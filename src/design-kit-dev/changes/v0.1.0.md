# design-kit-dev v0.1.0 Change Spec

## 변경사항 요약

- 디자인 기반, 웹·프로덕트·시각 콘텐츠 설계, 아트·크리에이티브 디렉션, 프로젝트 규칙 관리의 7개 skill을 제공한다.
- 디자인 이론과 맥락에 따른 반복·생략·재제공·강조·변주 기준을 공통 reference로 제공한다.
- 프로젝트 디자인 방향·베이스·전용 패턴의 저장과 재사용 계약을 제공한다.
- 기존 `judgment-kit:pro-designer`의 디자인 책임을 분해하고 기존 호출을 제거한다.
- 스킬 간 리소스 참조를 `$<plugin>:<skill>/<resource-path>` 식별자로 통일한다. 자기 skill 내부 상대 링크는 유지한다.

## 변경 상세

- 목적: 공통 디자인 지식과 역할별 결정, 프로젝트별 규칙 축적을 하나의 bundle로 제공한다.
- 범위: manifest, README, plugin·7개 skill spec, 7개 runtime skill, 공통 references와 프로젝트 문서 template.
- 근거: 사용자가 design-kit 재편과 기존 pro-designer 제거를 요청했고, 시각 콘텐츠와 반복의 맥락·의미·표현 기준을 구체화했다.
- 지속 계약은 plugin·skill spec이 소유한다. 이 문서는 신규 bundle과 migration 이력만 소유한다.
- 참조 규약: AGENTS.md의 규칙을 7개 runtime skill과 관련 spec·README에 적용한다. 개별 skill에 경로 해석 절차를 덧붙이지 않으며 버전은 0.1.0을 유지한다.

## 비목표

- marketplace 공개 등록, main 승격, 설치 캐시 갱신, commit·push·PR.
- 대상 프로젝트의 디자인 규칙 파일을 이번 플러그인 제작 작업에서 생성하는 일.

## 호환성 및 마이그레이션

- 기존 `$judgment-kit:pro-designer` 호출은 제거된다. 실제 판단 대상에 맞는 `$design-kit:<skill>` 호출을 선택한다.
- 9개 기준 축은 공통 지식과 전문·디렉션 판단에 재배치한다. 기존 UI 문구 기준과 새 시각 콘텐츠 책임을 구분한다.
- 프로젝트 문서가 없는 경우 자동 생성하지 않는다. 기록이 요청 범위일 때 기존 위치 또는 `docs/design.md`를 사용한다.

## 검증 기준

- 두 plugin의 dev/release manifest·skill 검증, source/release 정합성, runtime 링크, dev-only 제외, 제거된 skill의 활성 참조 부재.
- 식별자 기반 리소스의 소유 skill·대상 파일 존재와 build 후 release namespace 변환을 확인한다.
- 독립 read-only spec/runtime 검증과 반복·역할 선택·프로젝트 기록의 실제 요청 시나리오 평가.
- marketplace 등록과 실제 설치·시각 도구 실행은 별도 검증 범위다.
