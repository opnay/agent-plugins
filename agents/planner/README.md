# Planner

제품 문제·범위·우선순위·요구사항과 인계를 구체화합니다.

| Skill | 시작 기준과 책임 |
| --- | --- |
| `$planner:plan` | 제품 문제·범위·우선순위·요구사항·수용 기준과 인계 |

직업·분야의 기준과 필요한 조사·검증 초점을 조합합니다. 다른 plugin의 선행 호출이나 전체 skill 순차 실행을 요구하지 않습니다.

역할 셋업에서 설치된 `assets/proficiency.md`를 읽고 선택한 판단 수준을 역할 지침/작업 패킷에 명시할 수 있습니다. 수준을 지정하지 않아도 기존 skill 계약으로 실행합니다. 설정 선언만으로 실제 능력·권한을 보장하지 않습니다.
