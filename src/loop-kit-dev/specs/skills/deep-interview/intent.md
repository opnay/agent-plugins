# deep-interview 사용자 의도

- 실제 요구사항을 advisory answer가 아니라 질문 라운드로 잠그고 싶다.
- intent, scope, tradeoff, approval boundary를 명시적으로 확인하고 싶다.
- 충분한 clarity를 얻으면 다음 실행 경로로 자연스럽게 handoff하고 싶다.
- `deep-interview` 스킬을 `loop-kit`의 독립 하위 인터뷰 skill로 관리하고 싶다.
- `deep-interview-adaptation` 별도 문서는 스킬 스펙에 녹이고, `deep-interview` 스펙을 folder-based spec으로 관리하고 싶다.
- 하위 인터뷰 skill 안에는 상위 skill 맥락을 넣지 않고 싶다.
