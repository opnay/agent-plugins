# Thinking Intent Scenarios

이 문서는 `optimize-token`의 작업 전 thinking 최적화 의도를 예시로 고정합니다.
목적은 내부 추론을 공개하거나 방법을 장황하게 설명하는 것이 아니라, 답변이나 작업 전에 필요한 판단 문장을 간결하고 실행 가능하게 만드는 것입니다.

## 판정 기준

- 사용자 의도, 다음 행동, 검증 필요성, 승인 경계처럼 작업을 바꾸는 정보는 유지합니다.
- "같습니다", "수 있습니다", "좋겠습니다" 같은 완충 표현은 근거가 충분하면 더 직접적인 판단으로 줄입니다.
- 실제 불확실성은 지우지 않습니다.
- thinking 최적화는 간결한 작업 전 판단과 사용자에게 보이는 진행 보고에 적용합니다. 내부 추론 공개를 요구하지 않습니다.
- 최종 답변 작성 규칙은 runtime `references/response.md`가 소유합니다. 이 문서는 작업 전 판단 문장 예시만 소유합니다.

## 예시

### 설명 요청 후 구현 의향 확인

- Before: `사용자가 설명을 원하는 것 같습니다. 자세한 답변을 제공한 후 구현해 볼 의향이 있는지 물어볼 수 있습니다.`
- After: `사용자가 설명을 원하므로, 답변 후 구현 의향을 확인합니다.`
- 판정: 의도와 다음 행동은 유지하고, 추측형 표현과 장황한 질문 계획을 실행형 판단으로 줄였습니다.

### 관련 파일 확인

- Before: `이 작업은 파일을 수정해야 할 가능성이 있어 보이므로 먼저 관련 파일을 확인하는 것이 좋겠습니다.`
- After: `파일 수정 가능성이 있으므로 관련 파일을 먼저 확인합니다.`
- 판정: 작업 순서를 유지하면서 권유형 표현을 실행형 판단으로 바꿨습니다.

### 검증 필요성

- Before: `변경이 끝나면 문제가 해결됐는지 확인하기 위해 테스트를 실행하는 방향이 적절해 보입니다.`
- After: `변경 후 테스트로 해결 여부를 확인합니다.`
- 판정: 검증 목적은 유지하고 장황한 판단 표현을 줄였습니다.

### 불확실성 유지

- Before: `이 실패가 sandbox 때문인지 코드 문제인지는 아직 확실하지 않으므로, 로그와 재현 조건을 먼저 확인해야 할 것 같습니다.`
- After: `sandbox 문제인지 코드 문제인지 불확실하므로, 로그와 재현 조건을 먼저 확인합니다.`
- 판정: 실제 불확실성은 유지하고, 마지막 완충 표현만 줄였습니다.

### 승인 경계 유지

- Before: `이 명령은 외부 네트워크 접근이 필요할 수 있으므로, 실패하면 승인을 요청해서 다시 실행해야 할 수 있습니다.`
- After: `외부 네트워크 접근이 필요할 수 있으므로, 실패하면 승인 후 재실행합니다.`
- 판정: 승인 경계와 조건은 유지하고 반복 표현을 줄였습니다.

### 과압축 실패 예시

- Before: `검증은 아직 실행하지 않았고, 변경 범위가 넓어 회귀 위험이 남아 있습니다.`
- Bad: `검증 전입니다.`
- Good: `검증은 아직 실행하지 않았고, 넓은 변경 범위로 회귀 위험이 남아 있습니다.`
- 판정: 실패 또는 미검증 상태에서는 위험 정보를 삭제하면 안 됩니다.

### 사용자 정정 반영

- Before: `제가 사용자의 의도를 잘못 이해한 것 같습니다. 이전 답변의 방향을 수정해서 다시 설명해야 할 것 같습니다.`
- After: `이전 해석을 수정하고, 사용자의 의도에 맞춰 다시 설명합니다.`
- 판정: 불필요한 자기 평가와 추측 표현을 줄이고, 수정 행동을 남겼습니다.

### 작업 범위 제한

- Before: `이 변경과 직접 관련 없는 파일은 건드리지 않는 편이 좋겠습니다. 현재 요청 범위에 포함된 파일만 확인하고 수정해야 할 것 같습니다.`
- After: `관련 없는 파일은 제외하고, 요청 범위의 파일만 확인하고 수정합니다.`
- 판정: 범위 제한을 유지하면서 권유형 표현을 실행형 판단으로 바꿨습니다.

### 질문 라우팅

- Before: `이 경우에는 사용자의 선택에 따라 구현 방향이 달라질 수 있으므로, 먼저 어떤 방향을 원하는지 물어보는 것이 좋을 수 있습니다.`
- After: `구현 방향이 사용자 선택에 따라 달라지므로, 먼저 방향을 확인합니다.`
- 판정: 질문이 필요한 이유와 다음 행동을 유지하고, 장황한 가능성 표현을 줄였습니다.
