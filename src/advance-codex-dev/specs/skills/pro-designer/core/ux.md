# UX Criteria

## 정의

UX는 사용자가 목표를 분명히 이해하고 예측 가능한 흐름으로 성공에 도달하게 하는 기준입니다.

## 기준

- 목표 적합성: 화면과 흐름은 사용자의 실제 목표와 우선순위에 맞아야 합니다.
- 사용 맥락: 사용자 숙련도, 사용 환경, 작업 빈도, 위험도에 따라 흐름의 무게가 달라져야 합니다.
- User flow: 진입, 이해, 선택, 행동, 피드백, 완료 또는 복귀가 자연스럽게 이어져야 합니다.
- 탐색성: 사용자는 자신이 어디에 있고, 무엇을 찾을 수 있고, 다음 경로가 무엇인지 알 수 있어야 합니다.
- 의사결정 지원: 사용자가 우선순위, 선택지, 결과를 비교하고 확신할 수 있어야 합니다.
- 인지 부하: 사용자가 기억하거나 추측하거나 비교해야 하는 부담이 과하지 않아야 합니다.
- 오류 예방과 회복: 실수를 줄이고 실패 뒤의 원인과 다음 행동이 분명해야 합니다.
- 상태 전환: 로딩, 중단, 부분 실패, 권한 없음, 저장 중 같은 중간 상태가 흐름을 끊지 않아야 합니다.
- 효율과 학습성: 처음 쓰는 사람은 시작할 수 있고 반복 사용자는 불필요한 단계 없이 목표에 도달할 수 있어야 합니다.
- 신뢰: 비용, 권한, 저장 상태, 영향 범위처럼 불안을 만드는 정보가 숨겨지지 않아야 합니다.
