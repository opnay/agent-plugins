# deep-research-dev v0.1.0 Change Spec

## 변경사항 요약

- 여러 출처를 대조하는 `deep-research`의 개발 플러그인과 설치 가능한 배포면을 정의합니다.
- 주장별 근거·반대 근거·불확실성·인용을 갖춘 조사 워크플로와 보고서 계약을 제공합니다.
- 역할 기반 모델 라우팅과 명시적 위임 조건을 문서화합니다.

## 변경 목적

시장, 문헌, 기술·정책, 팩트체크, 실사에서 조사 결과를 독립적으로 검토할 수 있는 단일 스킬 플러그인을 제공합니다.

## 릴리즈 노트 기준

- 독자에게 보이는 변화: 명시·암시 호출, 적합·부적합한 작업, 모델 역할 예시, 증거 원장과 보고서 산출물을 안내합니다.
- 호환성 영향: 초기 플러그인 릴리스이므로 기존 공개 플러그인 표면을 변경하지 않습니다.
- migration 필요 여부: 없습니다.
- 운영자/사용자가 알아야 할 검증 결과: 개발 원본과 빌드된 배포면이 canonical validator를 통과했고, 8개 시나리오의 40개 체크가 모두 통과했으며, clean-context 검증에서 spec/runtime·trigger·release surface 정합성이 PASS 판정을 받았습니다.

## 변경 상세

### 조사 보고서 계약

- 목적: 결론뿐 아니라 근거, 반대 근거, 상충, 최신성, 불확실성을 감사 가능하게 남깁니다.
- 범위: 범위 잠금, 조사 지도, 원문 확보, 주장-근거 원장, 반증, 종합, 최종 감사
- 관련 표면: `specs/plugin.md`, `specs/skills/deep-research.md`, `skills/deep-research/SKILL.md`, `skills/deep-research/references/`
- 검증: clean-context verifier가 핵심 데이터 흐름, 출처 정책, 종료 조건, 보고서 필드의 spec/runtime 정합성을 PASS로 판정했습니다.

### 역할 기반 위임

- 목적: 모델 제품명이 바뀌어도 조사 설계, 독립 출처 스트림, 고정 스키마 추출의 책임을 유지합니다.
- 범위: 위임 기준, 작업 패킷, 조사자 출력 스키마, 최종 재확인 책임
- 관련 표면: `specs/skills/deep-research.md`, `README.md`, `skills/deep-research/references/model-routing.md`
- 검증: clean-context verifier가 독립 스트림 3개 이상이라는 최소 조건과 역할 기반 계약의 runtime 보존을 PASS로 판정했습니다.

### 매니페스트와 사용자 안내

- 목적: 개발·배포 플러그인의 식별자와 사용 시작점을 일관되게 제공합니다.
- 범위: 플러그인 메타데이터, skill 메타데이터, README, 트리거 fixture
- 관련 표면: `.codex-plugin/plugin.json`, `skills/deep-research/agents/openai.yaml`, `README.md`, `skills/deep-research/evals/trigger-prompts.csv`
- 검증: JSON·YAML·CSV 파싱, defaultPrompt 수·길이, 명시 호출 식별자, 긍정·부정·조건부 트리거를 통과했습니다.

## 비목표

- OpenAI의 독점 기능 또는 제품 모드인 `Deep Research`와 동일하다는 주장
- 새 MCP·앱·명령·훅 또는 외부 쓰기 기능
- 단순 조회, 단일 문서 요약, 코드 구현, 외부 시스템 변경, 지속 모니터링
- marketplace 공개 등록, Git 커밋, 브랜치, 태그 또는 원격 저장소 변경

## 호환성 및 마이그레이션

초기 릴리스이므로 기존 호출자의 마이그레이션은 없습니다. 개발 원본에서는 `$deep-research-dev:deep-research`, 빌드된 배포면에서는 `$deep-research:deep-research`를 사용합니다.

## 검증 기준

- canonical plugin·skill validator가 개발 원본과 빌드된 배포면에서 통과했습니다.
- 개발 원본과 배포면의 manifest·skill metadata·trigger fixture가 JSON·YAML·CSV로 파싱됐습니다.
- `pnpm build:plugin deep-research --force`가 루트 `deep-research/`를 생성하고 `specs/`·`changes/`를 제외했습니다.
- 배포면에서 `[DEV]`와 `deep-research-dev` 식별자 검색 결과가 0건이었습니다.
- clean-context verifier가 README, plugin spec, skill spec, runtime skill의 정합성을 PASS로 판정했습니다.
- 4개의 fresh executor가 8개 고정 시나리오의 40개 체크를 모두 통과했으며 재시도는 0회였습니다.
- 별도의 clean-context verifier가 트리거 표면과 release surface를 각각 PASS로 판정했습니다.

## 정식 규칙 승격 여부

- normative spec 또는 runtime 문서로 승격할 지속 규칙: 플러그인·skill spec, runtime skill, 출처·보고서·모델 라우팅 reference에 기록합니다.
- change spec에만 남길 release/migration 이력: v0.1.0의 최초 배포면 생성과 검증 결과를 기록합니다.
