# Branding Criteria

## 정의

Branding은 화면 표현이 특정 브랜드로 일관되게 인식되는지, 그리고 브랜드 색상, 자산, 문구 태도, 시각 모티프가 CTA, 상태 의미, 위험 의미, 제품 이해를 침범하지 않는지 판단하는 별도 표현 기준입니다.

## 기준

- 브랜드 식별성: 색상, 로고, 제품명, 시각 모티프, 문구 태도는 화면을 특정 브랜드로 인식하게 해야 합니다.
- 브랜드 자산 사용 강도: 로고, 심볼, 그래픽, 패턴, 일러스트는 화면 목적과 정보 밀도에 맞는 강도로 사용해야 합니다.
- 브랜드 색상 역할: 브랜드 색상은 brand, action, status, risk, background 역할을 구분하고 CTA나 상태색 의미를 침범하지 않아야 합니다.
- 브랜드 일관성: hero, navigation, CTA, card, form, chart, empty, error, success 상태가 같은 브랜드 언어로 이어져야 합니다.
- 브랜드와 톤: 선택한 목표 톤은 브랜드 성격과 맞아야 하지만, 톤 자체와 브랜드 식별성은 별도로 판단해야 합니다.
- 브랜드와 기능 의미: 브랜드 표현은 사용자가 클릭 가능성, 상태, 위험도, 권한, 비용, 결과를 판단하는 데 방해가 되면 안 됩니다.
- 브랜드 절제: 브랜드 자산이 반복되거나 과하게 커지면 정보 구조와 제품 사용성을 흐릴 수 있으므로 필요한 순간에만 강조해야 합니다.
- 브랜드 확장성: 브랜드 표현은 다크모드, 고대비, 지역화, 긴 콘텐츠, 추가 제품군, 새 상태가 생겨도 유지 가능해야 합니다.
- 브랜드 차별성: 일반적인 템플릿 느낌에 머물지 않고, 제품의 핵심 가치와 기억할 수 있는 시각 단서를 남겨야 합니다.
- 브랜드 신뢰성: 브랜드 표현은 과장된 약속이나 실제 기능과 맞지 않는 인상을 만들지 않아야 합니다.
