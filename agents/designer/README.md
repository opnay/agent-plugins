# Designer

디자인 원리·제품 경험·웹·시각 콘텐츠·디렉션·프로젝트 규칙을 제공합니다.

| Skill | 시작 기준과 책임 |
| --- | --- |
| `$designer:design-base` | 디자인의 원리와 공통 지식 |
| `$designer:product-designer` | 과업·흐름·상태·상호작용 |
| `$designer:web-designer` | 페이지 전달·탐색·반응형 표현 |
| `$designer:visual-content-designer` | 배너·카드뉴스·시각 콘텐츠 |
| `$designer:art-director` | 시각 콘셉트와 표현 언어 |
| `$designer:creative-director` | 메시지·핵심 아이디어·매체 간 전개 |
| `$designer:project-design-rules` | 프로젝트 디자인 방향·규칙의 기록과 적용 |

직업·분야의 기준과 필요한 조사·검증 초점을 조합합니다. 다른 plugin의 선행 호출이나 전체 skill 순차 실행을 요구하지 않습니다.

역할 셋업에서 설치된 `assets/proficiency.md`를 읽고 선택한 판단 수준을 역할 지침/작업 패킷에 명시할 수 있습니다. 수준을 지정하지 않아도 기존 skill 계약으로 실행합니다. 설정 선언만으로 실제 능력·권한을 보장하지 않습니다.
