# Deep Research Dev 플러그인 스펙

## 플러그인 목적

`deep-research-dev`는 시장 조사, 문헌 조사, 기술·정책 조사, 팩트체크, 실사처럼 여러 출처의 증거를 모아 독립적인 조사 보고서를 만드는 단일 목적 플러그인입니다.

## 플러그인 경계와 비목표

- 포함:
  - 조사 질문을 의사결정 목적, 범위, 기준 시점, 지역, 비교축, 산출물 형식으로 고정하는 일
  - 하위 질문과 출처 계획을 세우고 원문을 확보·대조하는 일
  - 주장별 근거·반대 근거·불확실성·인용을 추적하는 조사 보고서 작성
- 제외:
  - `judgment-kit:pro-researcher`가 소유하는 다음 제품·디자인·엔지니어링·품질 판단용 간결한 decision input
  - 단순 조회, 단일 문서 요약, 근거 없는 아이디어 발산
  - 코드 구현, 외부 시스템 변경, 지속 모니터링
  - OpenAI의 독점 기능 또는 제품 모드인 `Deep Research`와의 동일성 주장

## 처리하려는 작업 형태

- 시장·경쟁·규제·기술·문헌·기업 사실을 여러 출처로 확인하고 비교하는 작업
- 기준일, 지역, 정의, 표본, 이해관계에 따라 결론이 달라질 수 있는 팩트체크와 실사
- 찬반 근거와 증거 한계를 포함한 독립 조사 보고서가 필요한 작업

## 대표 표면과 사용법

- 매니페스트: `.codex-plugin/plugin.json`
- 사용자 안내: `README.md`
- 플러그인 스펙: `specs/plugin.md`
- skill 상세 스펙: `specs/skills/deep-research.md`
- 호출 식별자: `$deep-research-dev:deep-research`

명시 호출은 중요한 조사 범위나 보고서 형식을 직접 지정해야 할 때 적합합니다. 여러 출처의 대조와 인용 감사가 필요한 조사 요청은 암시 호출 대상입니다.

## 내장 skill 체계

- `deep-research`: 조사 범위 설정부터 증거 대조, 인용·불확실성 감사, 최종 보고서까지의 실행 워크플로를 소유합니다.
  - spec: `specs/skills/deep-research.md`

## SDD 운영 원칙

- 플러그인 스펙은 단일 목적, 경계, 사용 기준, skill 구성을 소유합니다.
- 조사 절차, 증거 판단, 위임, 보고서 계약은 `deep-research` skill spec이 소유합니다.
- skill 계약이 바뀌면 README, 매니페스트, plugin spec의 호출·경계·산출물 설명을 함께 점검합니다.
- release surface에는 `specs/`와 `changes/`를 포함하지 않습니다.

## 확장 원칙

- 새 skill은 독립적인 조사 산출물이라는 목적을 넓히지 않고, 현재 `deep-research`의 책임을 분리할 명확한 이유가 있을 때만 추가합니다.
- 조사 실행에 실제로 존재하는 MCP, 앱, 명령, 훅만 별도 표면으로 선언합니다.
- 모델 선택은 이름이 아니라 조사 설계, 독립 스트림, 고정 스키마 추출의 역할과 검증 책임으로 설명합니다.
