# Designer 개발 안내

[Plugin 계약](plugin.md)이 경계와 skill 선택을 소유합니다. [실제 사용 안내](../../designer/README.md)를 확인합니다.

- [design-base](skills/design-base/spec.md): 디자인의 원리와 공통 지식.
- [product-designer](skills/product-designer/spec.md): 과업·흐름·상태·상호작용.
- [web-designer](skills/web-designer/spec.md): 페이지 전달·탐색·반응형 표현.
- [visual-content-designer](skills/visual-content-designer/spec.md): 배너·카드뉴스·시각 콘텐츠.
- [art-director](skills/art-director/spec.md): 시각 콘셉트와 표현 언어.
- [creative-director](skills/creative-director/spec.md): 메시지·핵심 아이디어·매체 간 전개.
- [project-design-rules](skills/project-design-rules/spec.md): 프로젝트 디자인 방향·규칙의 기록과 적용.

과거 changes는 당시 이름·경로·계약을 보존합니다. 현재 호출·runtime은 plugin spec과 실제 manifest를 기준으로 확인합니다.
