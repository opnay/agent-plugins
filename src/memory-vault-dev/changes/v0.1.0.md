# memory-vault-dev v0.1.0 Change Spec

## 변경사항 요약

- `memory-vault-dev` 신규 dev 플러그인을 추가합니다.
- `memory-vault` passive skill을 추가합니다.
- `memv.py` helper script로 개인 에이전트 메모리 vault의 기본 문서, 카테고리 `INDEX.md`, `AGENTS.md` 표식 섹션을 만듭니다.
- 플러그인 경계를 특정 프로젝트 지식 저장소가 아니라 에이전트 사용 전반의 장기 기억 저장소로 고정합니다.
- 카테고리 `INDEX.md`를 문서 목록 인덱스로 고정하고, 지식 문서를 `<index>-<lowercase-hyphen-slug>.md` 형식으로 생성합니다.

## 변경 목적

에이전트가 어떤 작업을 하든 반복적으로 참고할 사용자 선호, 운영 결정, 환경 정보, workflow, 용어, 미해결 질문을 하나의 개인 vault root에 낮은 비용으로 누적할 수 있어야 합니다.

## 릴리즈 노트 기준

- 독자에게 보이는 변화: 새 `memory-vault` 플러그인과 `memory-vault` skill을 사용할 수 있습니다.
- 호환성 영향: 신규 플러그인이므로 기존 호출자 migration은 없습니다.
- migration 필요 여부: 없음.
- 운영자/사용자가 알아야 할 검증 결과: manifest JSON, release build, helper script dry-run, script unit test를 검증합니다.

## 변경 상세

### 신규 플러그인 표면

- 목적: 개인 에이전트 메모리 vault와 관리 규칙을 하나의 bundle로 제공합니다.
- 범위: manifest, README, plugin spec, change spec.
- 관련 표면: `src/memory-vault-dev/.codex-plugin/plugin.json`, `README.md`, `specs/plugin.md`.
- 검증: JSON 파싱과 build output 확인.

### 신규 passive skill

- 목적: skill 이름 없이도 기억, 사용자 선호, 장기 노트, durable agent memory 요청에서 자동 선택되는 workflow를 제공합니다.
- 범위: skill spec, runtime `SKILL.md`, helper script.
- 관련 표면: `specs/skills/memory-vault.md`, `skills/memory-vault/SKILL.md`, `scripts/memv.py`.
- 검증: skill validation과 helper script dry-run.

### 카테고리 지식 문서 인덱싱

- 목적: `INDEX.md`가 요약 저장소가 아니라 같은 폴더의 지식 문서와 하위 카테고리를 찾는 인덱스로 동작하게 합니다.
- 범위: skill spec, runtime `SKILL.md`, helper script, README, manifest prompt.
- 관련 표면: `specs/skills/memory-vault.md`, `skills/memory-vault/SKILL.md`, `scripts/memv.py`, `README.md`, `.codex-plugin/plugin.json`.
- 검증: helper script unit test와 dry-run에서 지식 문서 생성 및 index link 갱신 확인.

## 비목표

- 특정 프로젝트 전용 memory로 스킬 경계 고정.
- 외부 저장소 동기화.
- 대화 전문이나 작업 로그 자동 저장.
- 기존 문서 삭제 또는 `AGENTS.md` 전체 재작성.

## 호환성 및 마이그레이션

- 신규 플러그인이므로 migration은 없습니다.
- 대상 폴더에 기존 `AGENTS.md`가 있으면 표식 섹션만 추가 또는 갱신합니다.
- 대상 폴더 아래 별도 `memory-vault/` 하위 폴더는 만들지 않습니다.
- 카테고리는 1-2 depth 상대 경로로 제한합니다.
- 지식 문서는 1-2 depth 카테고리 아래 `<index>-<lowercase-hyphen-slug>.md` 형식으로 제한합니다.
- 기본 vault root는 `~/Workspace/Memory-vault`입니다.

## 검증 기준

- `python3 -m json.tool src/memory-vault-dev/.codex-plugin/plugin.json`
- `python3 src/memory-vault-dev/scripts/memv.py <tmpdir> --category Agents/Prompting --dry-run`
- `python3 src/memory-vault-dev/scripts/memv.py <tmpdir> --knowledge Programming/React/hook-rules --dry-run`
- `python3 -m unittest src/memory-vault-dev/scripts/tests/test_memv.py`
- `pnpm build:plugin memory-vault --force`
- release surface에 `specs/`와 `changes/`가 없어야 합니다.

## 정식 규칙 승격 여부

- normative spec 또는 runtime 문서로 승격할 지속 규칙: plugin boundary, passive trigger 계약, allowlist 파일 변경, 장기 기억 판별 규칙, 문서 분류 규칙, 1-2 depth category indexing, 지식 문서 파일명 규칙, `INDEX.md` 문서 목록 인덱싱, `AGENTS.md` 표식 섹션.
- change spec에만 남길 release/migration 이력: 신규 플러그인 추가 이력과 검증 기준.
