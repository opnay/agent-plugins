# pro-designer Scenario Testing Baseline

## 목적

`pro-designer` runtime skill이 UI, UX, Content, Quality 4축의 디자인 지식 기준을 실제 화면 판단에 적용할 수 있는지 평가한다.

## 평가 단위

- 대상 skill: `pro-designer`
- 평가 방식: 각 세부 기준마다 4개 시나리오
- 시나리오 유형:
  - `C` Creation: 새 화면을 설계한다.
  - `R` Review: 기존 화면을 비평한다.
  - `I` Improvement: 구체 개선안을 제안한다.
  - `E` Edge case: 상태, 제약, 위험, 다국어, 접근성 같은 까다로운 조건을 다룬다.

## 공통 체크리스트

- [critical] 해당 기준을 명시적으로 적용한다.
- [critical] UI, UX, Content, Quality 중 주축과 보조축을 구분한다.
- 화면 유형, 사용자 맥락, 작업 목적을 기준으로 판단한다.
- 고정 취향이나 일반론 대신 기준에 연결된 판단을 말한다.
- 남은 불확실성이나 추가로 필요한 맥락을 분리한다.

## Batch Plan

- 총 시나리오 수: 184개
- 권장 실행 단위: 기준별 4개 또는 축별 8-12개 smoke batch
- 첫 empirical pass 권장: 각 축에서 2개 기준을 골라 8개 시나리오만 실행
- 전체 실행은 subagent capacity에 맞춰 batch로 나눈다.
