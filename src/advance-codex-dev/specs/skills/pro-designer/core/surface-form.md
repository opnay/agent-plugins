# Surface & Form Criteria

## 정의

Surface & Form은 카드, 패널, 버튼, 입력 영역의 표면감, 깊이, 형태, 물성이 정보 위계와 행동 가능성을 돕는지 판단하는 별도 표현 기준입니다.

## 기준

- 표면 모델: flat, raised, inset, floating, glass, solid panel, paper-like, band 같은 표면 방식은 화면 목적과 정보 위계에 맞아야 합니다.
- 깊이: 떠 있음, 눌림, 같은 평면, 겹침의 단계는 레이어 관계와 상호작용 가능성을 예측하게 해야 합니다.
- 형태 언어: radius, border, divider, outline, shadow, bevel, padding, aspect ratio는 컴포넌트 역할과 제품 성격에 맞아야 합니다.
- 물성: 현실적인 재질, 유리감, 종이감, 플라스틱감, 부드러운 형태 같은 물성 표현은 제품 맥락과 사용 목적을 도와야 합니다.
- 촉각성: 누를 수 있음, 드래그할 수 있음, 선택됨, 비활성 같은 행동 가능성이 표면과 형태에서 드러나야 합니다.
- 계층 일관성: 같은 레벨의 카드, 패널, 모달, 툴바, 테이블, 리스트는 같은 깊이와 표면 규칙을 써야 합니다.
- 표면 필요성: 카드, 패널, band, plain section, list row, table row는 비교, 묶음, 독립 행동, 강조, 배경 분리 중 어떤 역할을 맡는지 분명해야 합니다.
- 구분 방식: 간격, 정렬, 타이포그래피, 색, 선, 표면 처리는 정보 그룹과 계층을 분명히 하되 같은 구분 역할을 중복하지 않아야 합니다.
- 밀도 적합성: 표면의 깊이, 장식성, 여백, 선의 강도는 정보 밀도와 사용 빈도에 맞아야 합니다.
- 상태 변화: hover, active, selected, pressed, disabled, loading 상태에서 표면과 깊이 변화가 예측 가능해야 합니다.
- 접근성과 성능: 그림자, blur, 투명도, 질감은 대비와 가독성을 해치거나 성능 부담을 만들지 않아야 합니다.
- 디자인 시스템 적합성: 기존 elevation, radius, border, shadow token과 충돌하지 않아야 하며 새 표면 규칙은 명시적 이유가 있어야 합니다.
- 확장성: 카드 수, 데이터량, viewport, 다크모드, 긴 콘텐츠가 바뀌어도 표면 규칙이 쉽게 무너지지 않아야 합니다.
