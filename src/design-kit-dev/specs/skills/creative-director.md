## 사용자 스펙 의도

- 디자인 베이스와 전문 디자이너, 아트 디렉터에 이어 크리에이티브 디렉터의 판단 범위를 둔다.
- 프로젝트 특성과 맥락에 맞는 반복·강조·일관성을 유지한다.

# creative-director 스킬 스펙

## 목적과 경계

- 누구에게 무엇을 어떤 핵심 아이디어와 경험으로 전달할지 결정한다.
- 메시지·콘셉트, 채널별 역할, 매체 간 연결과 일관된 전개를 소유한다.
- 사업·제품 전략을 임의 교체하지 않는다. 세부 시각 스타일, 모든 화면의 승인, 외부 게시를 소유하지 않는다.
- 대표 표면: `design-kit/skills/creative-director/SKILL.md`.

## 핵심 처리 계약

- 대상·상황·목표 반응·가치·실제 근거·브랜드·채널·제약을 파악하고 사실과 가정을 구분한다.
- 핵심 메시지와 전달 아이디어를 연결한다. 슬로건만으로 콘셉트를 대신하지 않는다.
- 의미 있는 선택이 남을 때만 대안을 비교한다. 적합성·차별성·실현 가능성·매체 확장성의 근거를 제시한다.
- 각 채널의 역할과 사용자 접점을 정한다. 동일 자산을 크기만 바꾸는 전개를 기본으로 삼지 않는다.
- 불변 메시지·용어·식별 단서와 변주 가능한 표현을 정한다. 반복은 기억·연결·강조 목적에 맞추고 빈도 피로를 고려한다.
- 브랜드 신뢰와 실제 제품 기능·증거를 보존한다. 성과나 전환 효과는 검증 전 가설이다.
- 아트 방향과 분야별 설계에 메시지·이유·제약·채널 역할·성공 신호를 넘긴다.

## 출력과 검토 질문

- 작업 크기에 맞는 creative brief: 대상·목표 반응·핵심 메시지·콘셉트·근거·채널 역할·반복/변주·확인할 가설.
- 독립 접점에서도 메시지가 이해되고, 전체 접점에서는 하나의 아이디어로 연결되는가?
- 관찰 가능한 성공 신호와 검증되지 않은 기대 효과가 구분되는가?

## 독립성·확장

- bundle 내 직접 실행 가능. 프로젝트 맥락과 design-base의 반복 reference를 명시적으로 읽는다.
- 시각 요소에 관한 판단이 필요하면 해당 base reference를 추가로 읽는다. 다른 역할의 선행 실행은 필요 없다.
- 새 기준은 메시지·콘셉트·매체 간 경험의 방향 결정에 연결한다.
