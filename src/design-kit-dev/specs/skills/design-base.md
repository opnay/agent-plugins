## 사용자 스펙 의도

- 색 대비, 보색, 공간감 등의 디자인 이론을 기본 베이스로 다룬다.
- 같은 맥락에서 동일한 용어·색상·패턴을 반복한다. 문구는 맥락에 따라 생략하거나 강조를 위해 반복한다.
- 같은 위계·역할·상태는 같은 시각 규칙을 사용한다. 그룹의 지속적 중요도와 상태 가시성·접근성은 구분한다.
- 중첩 표면은 독립 역할이 있어야 하며, 한쪽 선은 위치에 의미가 있는 indicator로 사용한다.

# design-base 스킬 스펙

## 목적과 경계

- 색채·시지각·구성·타이포·상호작용·움직임·반복 원리를 실제 디자인 결정에 연결한다.
- 일반 원리와 프로젝트의 선택값을 구분한다. 고정 미감, 팔레트, 토큰 값이나 업무별 workflow를 강제하지 않는다.
- 대표 표면: `design-kit/skills/design-base/SKILL.md`, `references/{color,space-type-surface,interaction-content,repetition}.md`.
- 사용: 디자인의 원인 설명, 표현 개선, 공통 기준 설계. 코드 오류만 다루는 요청에는 적용하지 않는다.

## 핵심 처리 계약

- 사용자·목표·매체·사용 빈도·위험·기존 규칙·실제 산출물에서 판단을 시작한다.
- 원리 > 적용 조건 > 선택에 미치는 영향 > 확인 방법을 연결한다. 항목 나열만으로 판단을 대신하지 않는다.
- 관찰, 추정, 결정, 검증 한계를 구분한다. 확보한 화면·동작 증거 이상으로 사용성이나 접근성을 확정하지 않는다.
- 경쟁하는 요구는 목표·비교 필요성·실수 비용을 기준으로 우선한다. 매력·기억·정서도 목적에 기여하면 표현 근거가 된다.
- 필요한 reference만 읽고 작업 크기에 맞춰 결과를 제시한다.

## 색채

- 색상·명도·채도, 보색·유사색, 동시대비, 배경과 면적 효과를 판단한다.
- 보색·조화가 가독성의 보증은 아니다. 실제 전경·배경, 텍스트·아이콘·focus·상태 대비를 확인한다.
- 브랜드·행동·상태·데이터 역할, 색 이외의 단서, 테마와 문화 차이, 감정적 연속성을 다룬다.
- 수치 접근성 주장은 적용 표준과 측정 근거가 있어야 한다.

## 시지각·공간·타이포·표면

- 근접·유사·연속·폐쇄·전경/배경을 그룹과 관계의 인지에 적용한다.
- 문서·콘솔·캔버스·지도·그리드·split view의 공간 모델, 영역 역할, 밀도·리듬, 비교 가치, 반응형 재구성을 판단한다.
- 크기·겹침·원근·명암·여백으로 깊이와 관계를 표현한다. 그림자만으로 공간을 설명하지 않는다.
- 서체·크기·굵기·행간·행장·언어·실제 콘텐츠로 읽기 위계를 정한다.
- 그룹은 자식이 암시할 지속적 화면 중요도의 의미상 상한을 정한다. px·variant 제한이 아니며 더 큰 중요도는 소속·그룹 위계를 다시 판단한다.
- 상태 가시성, focus, 대비, 읽기 순서, 접근 가능한 조작 목표는 낮은 위계로 약화하지 않는다.
- 중첩 표면은 독립 정보·행동·상태·레이어가 있어야 한다. 단순 그룹은 간격·정렬·행·구분선을 우선한다.
- 전체 outline은 경계, 부분 선은 선택·상태·방향·소속·관계의 indicator다. 위치 의미와 radius·RTL 일관성을 확인한다.
- 재질·깊이·반경·선·그림자는 역할과 프로젝트 토큰에 맞추며 같은 역할에서 반복한다.

## 상호작용·시간·언어

- 행동 단서, 즉시·진행·결과 피드백, 인지·선택 부담, 예방·회복을 다룬다.
- 정상·로딩·빈 상태·오류·비활성·권한·성공·부분 성공·취소를 작업에 필요한 범위로 확인한다.
- 모션은 연속성·방향·변화 이해에 기여해야 하며 reduced motion과 지연·성능을 고려한다.
- 라벨·CTA·안내·오류·상태는 실제 시스템 사실과 다음 행동을 전달한다. 용어 일관성과 문구 노출 횟수는 구분한다.

## 반복

- 목적: 일관성·학습, 연결·리듬, 강조·기억.
- 같은 맥락의 동일 의미·역할은 용어·색·형태·배치·상호작용 규칙을 반복한다. 다른 의미는 구별한다.
- 주변 맥락으로 충분하면 노출을 생략할 수 있다. 독립 노출·스크롤·화면 전환·보조기술에서 맥락을 잃으면 재제공한다.
- 핵심 메시지를 의도적으로 반복할 수 있다. 횟수·위치·간격·크기·변주로 강조와 피로를 조절한다.
- 적용 맥락, 반복 요소, 유지할 의미·역할, 생략·변주 조건을 연결한다. 모든 곳을 같은 모양으로 만들지 않는다.

## 출력과 검토 질문

- 결정, 적용 원리·조건, 근거, 중요한 tradeoff, 확인 결과·미확인 범위를 작업 크기에 맞게 제시한다.
- 같은 의미가 일관되고 다른 의미가 구별되는가? 맥락 생략 뒤에도 사용자가 뜻을 복원할 수 있는가?
- 실제 크기·테마·긴 콘텐츠·상태에서도 목적과 접근성이 유지되는가?

- 다른 역할의 선행 실행은 필요 없다. 이론은 이 skill의 reference가 소유하며 역할별 본문에 복제하지 않는다.
- 새 이론은 실제 선택과 검증을 바꿀 때만 포함한다.
