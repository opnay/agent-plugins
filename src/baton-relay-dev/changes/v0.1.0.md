# baton-relay-dev 0.1.0 Change Spec

## 변경사항 요약

- `baton-relay-dev` 신규 dev plugin source를 추가한다.
- 대표 skill `manager`를 추가한다.
- worktree별 fresh subagent lifecycle, commit/rebase handoff, prepared commit integration, cleanup gate를 초기 계약으로 고정한다.
- 20개 scenario evaluation에서 드러난 read-only, generated output, commit approval, missing verification, unresolved conflict 경계를 보강한다.
- `manager` skill spec을 folder-based 구조로 전환하고, 전체 relay flow graph를 `intent.md`에 둔다.
- `manager`의 구조분해 기준을 실무형 `workstream / write scope / dependency / parallel blockers / acceptance`로 정리하고, Markdown `Workflow > Jobs > Runs` todo 계획 문서를 필수 산출물로 둔다.
- `skills/manager/templates/workflow-plan.md`에 frontmatter 기반 Markdown workflow plan 문서 템플릿을 둔다.

## 변경 목적

큰 작업을 메인 에이전트가 직접 구현하지 않고, git worktree로 격리된 subagent 작업 단위에 맡긴 뒤 commit 단위로 회수하는 orchestration plugin을 시작한다.

## 릴리즈 노트 기준

- 독자에게 보이는 변화: `baton-relay` plugin과 `manager` skill이 추가된다.
- 호환성 영향: 신규 plugin이므로 기존 호출자 migration은 없다.
- migration 필요 여부: 없음.
- 운영자/사용자가 알아야 할 검증 결과: manifest, skill metadata, release surface, marketplace entry를 검증해야 한다.

## 변경 상세

### 신규 plugin source

- 목적: worktree-based subagent orchestration을 하나의 coherent bundle로 제공한다.
- 범위: `src/baton-relay-dev/.codex-plugin/plugin.json`, `README.md`, `specs/plugin.md`.
- 관련 표면: plugin manifest, README, plugin spec.
- 검증: JSON parse, release build, release manifest 확인.

### manager skill

- 목적: 메인 에이전트가 manager로 동작하고 subagent가 bounded worktree task를 수행하는 계약을 제공한다.
- 범위: `specs/skills/manager/`, `skills/manager/SKILL.md`.
- 관련 표면: skill spec, runtime skill.
- 검증: skill metadata, runtime/dev-only path leak, spec/runtime alignment, 20개 scenario evaluation 확인.

### folder-based skill spec

- 목적: 사용자 의도와 전체 그래프, index, 세부 책임 계약을 분리한다.
- 범위: `intent.md`, `spec.md`, `planning.md`, `decomposition.md`, `lifecycle.md`, `handoff.md`, `failure.md`.
- 관련 표면: skill spec, plugin spec.
- 검증: folder-based spec 구조와 plugin spec 경로 확인.

### workflow plan contract

- 목적: subagent dispatch 전에 사람이 읽고 갱신하는 계획 todo 문서를 만들게 한다.
- 범위: `planning.md`, `decomposition.md`, runtime `SKILL.md`.
- 관련 표면: skill spec, runtime skill.
- 검증: runtime plan section, spec map, release build 확인.

### workflow plan template

- 목적: manager가 작성할 계획 문서의 metadata와 체크리스트 모양을 고정한다.
- 범위: `skills/manager/templates/workflow-plan.md`, `specs/skills/manager/planning.md`, runtime `SKILL.md`.
- 관련 표면: skill runtime template, skill planning spec, runtime skill.
- 검증: frontmatter template file과 runtime reference 확인.

## 비목표

- 실제 subagent spawn 도구 구현.
- GitHub PR, push, release publication 자동화.
- 특정 언어/프레임워크 구현 전략.

## 호환성 및 마이그레이션

- 신규 plugin이므로 기존 plugin migration은 없다.
- 향후 skill 추가 시 plugin boundary를 worktree relay orchestration으로 유지한다.

## 검증 기준

- `pnpm build:plugin baton-relay --force`
- JSON parse for dev and release manifests, marketplace.
- release surface에 `specs/`와 `changes/`가 없어야 한다.
- `manager` runtime skill이 dev-only spec path를 실행 지시로 포함하지 않아야 한다.
- `src/baton-relay-dev/specs/skills/manager/intent.md`에 전체 flow graph가 있어야 한다.
- runtime `manager`가 Markdown `Workflow > Jobs > Runs` plan을 요구해야 한다.
- `src/baton-relay-dev/skills/manager/templates/workflow-plan.md`가 있어야 하고 runtime `manager`가 이를 참조해야 한다.

## 정식 규칙 승격 여부

- normative spec 또는 runtime 문서로 승격할 지속 규칙: Markdown workflow plan template, 실무형 job 분해 기준, subagent lifecycle, rebase handoff, prepared commit integration, cleanup gate, folder-based spec 구조.
- change spec에만 남길 release/migration 이력: initial creation history.
