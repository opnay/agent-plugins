# Writer 스킬 스펙

## 목적·경계

승인된 위키에 새 지식·사용자 정보·결정·작업 결과를 반영하고 탐색 가능한 연결을 유지합니다.
작업 조건 도출·변경·진행·충족 판정은 manager 또는 작업 담당자가 소유합니다. writer는 외부 재조사, 제품 구현, 임의의 다른 위키 선택, 전체 구조의 상시 재편을 소유하지 않습니다.

## 대표 표면

- 실행 지침: `agent/agent-wiki/skills/writer/SKILL.md`, 호출: `$agent-wiki:writer`.
- 사용자·작업 담당자·다른 도구가 제공한 사실·자료·결정·작업 상태에서 바로 시작합니다.
- 사용자 스펙 의도는 [intent.md](intent.md)에 보존합니다.

공통 root·탐색·구조 기준은 [공통 위키 계약](../../wiki.md)을 따릅니다. 설치 runtime은 이 계약들을 자체 포함하며 작성용 spec에 의존하지 않습니다.

## 독립성·확장 원칙

- 단독 실행을 강제합니다. manager 사전 실행·체크리스트·다른 skill 출력이 필수 입력은 아닙니다.
- 기억 선택·보존·저장 책임 안에서 확장하며 작업 조건 도출·충족 판정·제품 구현을 끌어오지 않습니다.
- 새 계약은 해당 책임의 child spec이 소유하며 index와 다른 child에 반복하지 않습니다.
