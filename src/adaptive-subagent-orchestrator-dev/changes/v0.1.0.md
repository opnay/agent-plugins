# adaptive-subagent-orchestrator-dev 0.1.0 Change Spec

## 변경사항 요약

- 단일 skill 플러그인 `adaptive-subagent-orchestrator-dev`를 추가합니다.
- `adaptive-subagent-orchestrator` instruction-only runtime skill과 references를 추가합니다.
- marketplace 등록 가능한 release surface 생성을 준비합니다.

## 변경 목적

복잡한 software-engineering task에서 독립 workstream을 감지하고, 병렬 위임 이점이 분명할 때만 bounded subagent를 최소 수로 생성하는 재사용 가능한 Codex skill을 배포합니다.

## 릴리즈 노트 기준

- 독자에게 보이는 변화: `$adaptive-subagent-orchestrator` skill이 추가됩니다.
- 호환성 영향: 새 플러그인 추가이므로 기존 플러그인 동작을 바꾸지 않습니다.
- migration 필요 여부: 없음.
- 운영자/사용자가 알아야 할 검증 결과: skill validation, plugin validation, release build, JSON/YAML 정적 검증을 통과해야 합니다.
