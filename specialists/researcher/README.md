# Researcher

질문·분야·위험에 맞춰 조사 기준·방법·깊이를 정하고 실제 근거·반증·불확실성을 종합합니다.

| Skill | 시작 기준과 책임 |
| --- | --- |
| `$researcher:research` | 질문·분야·위험에 맞는 조사 기준/방법/깊이와 근거·반증·불확실성 |

직업·분야의 기준과 필요한 조사·검증 초점을 조합합니다. 다른 plugin의 선행 호출이나 전체 skill 순차 실행을 요구하지 않습니다.

제공된 자료로 답할 수 있는 좁은 질문부터 중요한 다출처 조사까지 같은 skill을 사용합니다. 근거 수집이 필요 없는 단순 변환·창작은 대상이 아닙니다. 출처 정책과 심층 보고 계약은 skill의 조건에 따라 읽습니다. 조사 자체는 직접 수행할 수 있으며 별도 agent나 orchestrator를 요구하지 않습니다.
