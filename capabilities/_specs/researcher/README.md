# Researcher 개발 안내

[Plugin 계약](plugin.md)이 경계와 skill 선택을 소유합니다. [실제 사용 안내](../../researcher/README.md)를 확인합니다.

- [research](skills/research/spec.md): 질문·분야·위험에 맞는 조사 기준/방법/깊이와 근거·반증·불확실성.

과거 changes는 당시 이름·경로·계약을 보존합니다. 현재 호출·runtime은 plugin spec과 실제 manifest를 기준으로 확인합니다.

[검증 계획](validation-plan.md)과 [실제 검증 결과](validation-results.md)는 native 로딩·행동 비교·효과와 한계를 구분합니다.
