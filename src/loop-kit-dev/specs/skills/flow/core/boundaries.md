# flow boundary 계약

- active flow: selected main flow.
- parent flow: candidate/config producer.
- sub-flow candidate: pending flow option.
- phase: active flow 내부 step.
- handoff: readiness/blocker/next-intake/commit-ready routing result.
- repair: current flow 내부 처리, reviewable artifact 발생 시 새 flow.
- check: phase inside, candidate pending, handoff routing, repair classified.
