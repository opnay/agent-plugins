# Response Intent Scenarios

같은 입력에서 `light`, `standard`, `extreme` 차이를 고정하는 예시입니다.
명시된 호출 모드는 따르고, 미명시 때만 가장 약한 충분 강도를 추정합니다.
어떤 단계에서도 실패/미검증, 승인 경계, 경로, 명령어, 날짜, 버전, 수치는 삭제하지 않습니다.

| 시나리오 | 요청 | Before | light | standard | extreme |
| --- | --- | --- | --- | --- | --- |
| 일반 간결화 | `짧게 말해줘.` | `확인해 보니 설정 파일의 경로가 실제 파일 위치와 일치하지 않아서 문제가 발생했을 가능성이 높아 보입니다.` | `설정 파일 경로가 실제 위치와 다릅니다.` | `설정 경로가 틀렸습니다.` | `원인: 설정 경로 불일치.` |
| 말투/형식 | `군더더기 없이 정리해줘.` | `전체적으로 보았을 때 이 변경은 요청하신 범위 안에 있으며, 특별히 추가로 설명드릴 만한 큰 문제는 없어 보입니다.` | `이 변경은 요청 범위 안에 있습니다. 큰 추가 이슈는 없습니다.` | `요청 범위 안입니다. 큰 추가 이슈는 없습니다.` | `범위: 적합. 이슈: 없음.` |
| 긴 보고 | `핵심만 요약해줘.` | `세 파일을 수정했고, 테스트는 두 개 실행했습니다. 첫 번째 테스트는 통과했지만 두 번째 테스트는 네트워크 제한으로 실행하지 못했습니다. 따라서 기능 자체는 확인됐지만 외부 연동 경로에는 아직 불확실성이 남아 있습니다.` | `세 파일을 수정했고, 한 테스트는 통과했습니다. 외부 연동 테스트는 네트워크 제한으로 실행하지 못해 불확실성이 남아 있습니다.` | `세 파일을 수정했고 핵심 테스트는 통과했습니다. 외부 연동 테스트는 네트워크 제한으로 미실행이라 해당 경로는 불확실합니다.` | `수정: 3파일. 검증: 핵심 통과, 외부 연동 미실행. 리스크: 외부 경로 불확실.` |
| 리뷰 결과 | `리뷰 결과만 짧게.` | `가장 중요한 문제는 에러 처리 경로에서 null 값이 들어올 때 예외가 발생할 수 있다는 점입니다. 이 문제는 사용자 입력이 비어 있을 때 재현될 수 있으며, 현재 테스트에는 해당 케이스가 없습니다.` | `가장 큰 문제는 null 입력에서 예외가 날 수 있다는 점입니다. 빈 입력 테스트가 없습니다.` | `주요 문제: null 입력에서 예외가 날 수 있습니다. 빈 사용자 입력 테스트가 없습니다.` | `문제: null 예외 가능. 테스트: 빈 입력 없음.` |
| 상태값 | `상태만.` | `검증은 아직 실행하지 않았고, 변경 범위가 넓어서 회귀 위험이 남아 있습니다.` | `검증은 아직 실행하지 않았고, 넓은 변경 범위로 회귀 위험이 남아 있습니다.` | `미검증이며, 넓은 변경 범위로 회귀 위험이 남아 있습니다.` | `상태: 미검증. 위험: 넓은 변경 범위.` |

| 승인 경계 | `최대한 짧게.` | `커밋은 아직 실행하지 않았고, push와 PR 생성도 승인되지 않았습니다.` | `커밋은 아직 실행하지 않았고, push와 PR도 승인되지 않았습니다.` | `커밋 미실행. push/PR 미승인.` | `커밋: 미실행. push/PR: 미승인.` |
