# jev v0.1.0 Change Spec

## 변경사항 요약

- Go 기반 Choice CLI와 `$jev:jev` 사용 스킬.
- `~/.agents/jev.toml`, 오프라인 config 관리, 토큰 stdin 저장.
- answer-only·JSON·pick 출력, 선택 확률 threshold와 종료 코드.
- install/uninstall/doctor 커맨드, `go run . install` 설치 진입점과 marketplace 등록.

## 변경 목적

특정 검증 업무에 결합하지 않고, 자연어 질문과 선택지로 hosted Jev를 호출하는 공통 실행 기반을 제공한다.

## 변경 상세

### CLI와 설정

- 관련 표면: [CLI spec](../specs/cli.md), `jev/scripts/`, `jev/README.md`.
- 기본값 우선순위, token 비노출, 원자적 설정 저장, API·threshold 실패 계약을 자동 테스트한다.

### 플러그인과 스킬

- 관련 표면: [plugin spec](../specs/plugin.md), [skill spec](../specs/skills/jev.md), runtime skill·manifest·marketplace.
- 스킬은 필요한 문맥과 선택지 구성 및 결과 사용을 담당하며, CLI 구현이나 전체 검증 정책을 중복 소유하지 않는다.

### CLI 유지보수

- install은 실행 중인 바이너리를 복사하며, 동일 설치는 성공·다른 파일 교체는 명시적 force로 처리한다.
- 최초 설치와 소스 갱신은 `go run . install`을 사용한다. 별도 셸 래퍼와 전용 테스트를 제거하고 CLI 자체의 유지보수 테스트는 유지했다.
- uninstall은 식별 가능한 Jev 파일만 제거하고 설정·토큰을 보존한다.
- doctor는 로컬 설치·PATH·설정·토큰 유무를 진단한다. 자동 실행·수정·API 인증 호출은 하지 않는다.
- 관련 표면: CLI·skill spec, `jev/scripts/`, runtime skill, README, manifest.

## 비목표

로컬 모델, 문서 자동 검증, 배치·다른 primitive, 다른 플러그인 자동 연동, 자동 재시도.

## 호환성 및 마이그레이션

최초 버전이며 기존 플러그인 계약은 변경하지 않는다. 플러그인 등록과 바이너리 설치는 별개다. 사용자 홈 설정·토큰은 개발 과정에서 생성하지 않는다.

## 검증 기준

- Go 테스트·vet·빌드, 임시 경로의 설치 동작.
- manifest·marketplace JSON, plugin·skill validator, spec/runtime 독립 검증.
- 실제 API 호출은 토큰과 호출 권한이 있을 때 별도 검증한다.

## 정식 규칙 승격 여부

지속 계약은 plugin·CLI·skill spec이 소유한다. 이 문서는 최초 버전의 변경 범위만 기록한다.

## 구현 검증 기록

### 최초 구현 — 2026-09-21

- Go 테스트, `go vet`, 바이너리 빌드 통과. 설정·API 테스트는 임시 경로와 가짜 transport를 사용했다.
- 임시 디렉터리 설치·교체, 기존 파일 보호, 빌드 실패 시 기존 파일 보존, symlink·디렉터리 거부 통과.
- plugin·skill validator, marketplace JSON·경로, 포맷·diff 검사 통과.
- 독립 read-only 검증 두 건 통과: skill·사용 표면 정합성, CLI spec·구현 정합성. 이 검증은 실행 테스트를 대체하지 않는다.
- 실제 API 호출, 사용자 환경 설치, 커밋·푸시·릴리즈는 수행하지 않았다.

### 유지보수 커맨드 — 2026-09-21

- 설치·동일 바이너리 재설치·기존 파일 보호·자기 제거·설정 보존을 임시 경로에서 검증했다.
- doctor의 정상 상태, 설치 누락, PATH 누락·충돌, 토큰 누락, 설정 오류·권한·JSON/pick 조합을 확인했다. API 호출이나 설정 변경은 없었다.
- skill·사용 안내의 독립 정합성 검토 통과. 코드 검토에서 발견한 빈 `--dir`의 기본 경로 fallback과 명시적 빈 pick 배열 저장 누락을 수정하고 회귀 테스트로 확인했다.
- 수정 후 전체 Go 테스트·vet·빌드, plugin·skill 형식, 포맷·diff 검사 통과. 사용자 환경 설치·제거, API 호출, 커밋·푸시는 수행하지 않았다.

### 셸 래퍼 제거와 로컬 설치 — 2026-09-21

- 셸 래퍼와 전용 테스트를 제거하고 설치 안내를 `go run . install`로 통일했다.
- Go bootstrap 회귀 테스트를 포함한 전체 테스트·vet, plugin·skill validator, staged diff 검사를 통과했다.
- 최종 skill spec/runtime 독립 검증은 통과했다. 설치 표면 검토는 동시 대상 교체 경쟁조건을 지적했다: 검사 직후 다른 프로세스가 대상을 바꾸면 force 설치나 제거가 바뀐 파일에 적용될 수 있다. 통상적인 단일 실행은 검증했으며, 외부 동시 변경 보호는 이번 범위에서 구현하지 않았다.
- `go run . install`로 `/Users/devsisters/.local/bin/jev` 설치를 완료했다. 설정·토큰·셸 설정은 변경하지 않았고 실제 API 호출은 하지 않았다.
