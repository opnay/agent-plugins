# judgment-kit v0.2.0 Change Spec

## 변경사항 요약

- `pro-quality-manager` runtime과 소유 skill spec을 제거합니다.
- Judgment Kit의 현재 책임을 리서치·제품 기획 두 skill로 맞춥니다.
- 산출물 검증은 `$quality:verify`로 안내합니다.

## 변경 상세

품질을 별도 전문가 역할로 묶는 기존 skill을 정리하고, 산출물 특성에 따른 검증 행동은 Quality의 기존 계약을 사용합니다. 두 manifest의 버전은 0.2.0이며 설명·키워드·prompt와 사용/개발 README·plugin spec·root 안내를 실제 두 skill에 맞춥니다. 남은 skill의 실행 계약과 marketplace 순서는 유지합니다.

## 비목표

기존 품질 관리 계약 전체의 Quality 이전, 새 역할 추가, 출시 승인 제공, 사용자 설치 갱신, push·main 머지는 포함하지 않습니다. 이전 버전의 change spec과 검증 결과는 당시 관찰로 보존합니다.

## 호환성과 마이그레이션

`$judgment-kit:pro-quality-manager` 호출은 더 이상 제공하지 않습니다. 산출물 검증 계획·실행·근거 판정이 필요한 호출은 `$quality:verify`로 변경합니다. 두 skill은 동일 계약의 이름 변경이 아니며 release 관리나 승인 절차를 자동 대체하지 않습니다. 리서치·기획 호출은 유지합니다. 사용자 환경의 기존 설치는 별도 갱신 전까지 남을 수 있습니다.

## 검증 기준

- runtime·소유 spec·manifest prompt에 제거된 skill이 없습니다.
- Judgment Kit의 실제 두 skill·공통 metadata·사용 표면과 버전이 일치합니다.
- 현재 안내의 제거된 호출, 상대 링크, JSON 형식과 diff 공백을 확인합니다.
- 남은 skill과 Quality runtime, 두 marketplace의 내용은 변경 전과 동일합니다.
