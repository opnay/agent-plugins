# 사용자 스펙 의도

- `judgment-kit`의 3개 skill을 만든 공통 기준은 전문가가 자기 분야에서 문제를 판단하는 방식이다.
- `pro-engineering`은 전문가로서의 engineering flow를 적용한 원형이고, 그 flow를 planner와 designer 쪽에도 적용한다.
- `judgment-kit`에 추가할 전문가 포지션으로 researcher와 QA가 적합하다.
- tester는 검증에 가깝다면 QA는 품질 관리에 가까워 더 넓은 범위를 가져야 한다.
- QA보다 QM, 즉 quality manager로 두면 테스트 실행보다 품질 관리와 release confidence 책임이 더 선명하다.
- tester는 별도 skill보다 quality manager 안의 validation strategy 또는 scenario coverage 하위 기능으로 둔다.
