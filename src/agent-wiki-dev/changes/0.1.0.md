# 0.1.0 변경 기록

## 변경사항 요약

- 작업 기록·판단별 근거·자료 요약 연결, 사건별 누적, 과거 판단 복원과 선택적 URL 조사 위임을 지원합니다.

- 웹 조사 후 기록 필요성을 평가하고 새 지식·결정 근거·정정은 기록하며 단순 탐색·중복은 생략합니다.
- 직접 파일 25개·루트 0 기준 깊이 4·복합 폴더명 두 부분 제한을 적용합니다. writer가 영향 범위를 정리하고 reader·researcher는 발견한 위반만 보고합니다.
- 설정 파일 위치는 `~/.agents/config.wiki.toml`입니다.

- reader·researcher·writer로 위키 탐색·조사·문서 반영 책임을 제공합니다.
- 인덱스 상하 구조, 일반 문서 자유 연결, 루트 왕복 도달을 유지합니다.
- 사건 기반 기록과 영향 범위에 맞춘 정리를 적용합니다.

## 변경 상세

- CLI의 설정·설치 계약과 초기 버전은 유지합니다. 기존 TOML 및 Rust 코드는 변경하지 않습니다.
- 각 스킬은 독립 입력에서 시작하며 필수 호출 순서나 별도 서브에이전트를 요구하지 않습니다.
- README·manifest는 세 역할의 시작 조건과 기록 권한을 설명합니다.
- 검증 기준: spec/runtime 정합성, description의 선택 범위, 세 역할의 실행 smoke 시나리오, 배포본 일치와 dev-only 경로 비의존입니다.

## 작업 이력 복원과 자료 재사용

- 목적: 과거 해결 과정과 판단 근거를 블로그 자료로 복원하고 반복 자료 조회를 줄입니다.
- 표면: reader·researcher·writer spec/runtime, plugin spec·README·manifest를 맞춥니다.
- 비목표: 자동 백그라운드 기록, 기존 위키 일괄 이관, CLI 변경, 설치 캐시 갱신, 커밋·발행은 포함하지 않습니다.
- 호환성: 0.1.0과 기존 경로·권한·폴더 제한을 유지합니다. 문서 연결 모델이며 새 디렉터리를 강제하지 않습니다.
- 검증: 독립 spec/runtime 검토, 과거 작업 복원·자료 위임 시나리오, skill 정적 검사, release build와 source 일치.
