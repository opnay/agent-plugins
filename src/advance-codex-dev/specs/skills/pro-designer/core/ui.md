# UI Criteria

## 정의

UI는 사용자가 정보를 읽고, 구조를 이해하고, 가능한 행동을 판단하는 인터페이스 표면의 기준입니다.

## 기준

- 정보 구조: 중요한 정보, 자주 쓰는 행동, 위험한 행동의 우선순위와 그룹이 분명해야 합니다.
- 레이아웃: 배치, 정렬, 밀도, 스캔 경로가 화면 목적과 정보 관계를 드러내야 합니다.
- 시각 위계: 크기, 간격, 색, 타이포그래피, 아이콘, 이미지가 중요도와 행동 우선순위를 드러내야 합니다.
- 상태 표현: 기본, 선택, 비활성, 로딩, 오류, 성공, 빈 상태의 의미가 구분되어야 합니다.
- 컴포넌트 역할: 버튼, 링크, 입력, 토글, 메뉴는 행동 성격에 맞게 쓰여야 합니다.
- 일관성: 같은 의미의 행동, 상태, 정보는 같은 컴포넌트와 시각 규칙으로 표현되어야 합니다.
- 접근성: 대비, 가독성, 포커스, 터치 목표, 키보드 탐색 가능성이 유지되어야 합니다.
- Affordance: 행동 가능한 요소는 행동 가능성과 위험도를 예측할 수 있게 보여야 합니다.
- 즉시 피드백: 버튼 클릭, 입력, 전환 같은 사용자 행동은 즉각적인 시각 반응을 줘야 합니다.
- 처리 상태: 지연되는 작업은 진행 중임을 드러내고 사용자가 기다릴 이유를 알 수 있어야 합니다.
- 결과 상태: 완료, 실패, 취소, 부분 성공은 다음 행동과 함께 구분되어야 합니다.
