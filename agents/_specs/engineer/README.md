# Engineer 개발 안내

[Plugin 계약](plugin.md)이 경계와 skill 선택을 소유합니다. [실제 사용 안내](../../engineer/README.md)를 확인합니다.

- [spec](skills/spec/spec.md): 구현 가능한 소프트웨어 행동 계약.
- [engineering](skills/engineering/spec.md): 기술·구조·데이터 모델·통합·운영 방향.
- [code](skills/code/spec.md): 코드 구현·테스트·리뷰와 수정.
- [maintenance](skills/maintenance/spec.md): 의존성·노후화·기술/테스트 부채의 유지보수.

과거 changes는 당시 이름·경로·계약을 보존합니다. 현재 호출·runtime은 plugin spec과 실제 manifest를 기준으로 확인합니다.
