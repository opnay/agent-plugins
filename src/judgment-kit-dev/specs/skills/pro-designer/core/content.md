# Content Criteria

## 정의

Content는 화면 안의 언어가 사용자 맥락에 맞게 의미, 위험, 결과, 다음 행동을 전달하는 기준입니다.

## 기준

- 정보 우선순위: 먼저 읽어야 할 내용과 나중에 봐도 되는 내용이 문구 구조에서 구분되어야 합니다.
- 구조 문구: 화면 제목, 섹션 제목, 그룹명은 사용자의 스캔 순서와 맥락 파악을 도와야 합니다.
- 라벨: 사용자가 항목의 의미와 차이를 바로 이해할 수 있어야 합니다.
- 용어 이해: 전문용어, 약어, 내부 용어는 사용자 언어와의 간극을 줄여야 합니다.
- CTA: 행동 문구는 결과와 의도를 분명히 드러내야 합니다.
- 안내: 설명은 필요한 순간에만 맥락적으로 제공되고, 이미 아는 내용을 반복하지 않아야 합니다.
- 오류 문구: 문제 원인과 회복 방법을 알려야 합니다.
- 상태 문구: 성공, 경고, 로딩, 저장 완료 같은 상태는 사용자가 다음 행동을 판단할 수 있게 말해야 합니다.
- 시스템 사실성: 문구는 실제 시스템 상태, 처리 결과, 제한사항을 과장 없이 반영해야 합니다.
- 위험 문구: 삭제, 결제, 권한 변경처럼 영향이 큰 행동은 결과와 되돌리기 가능성을 분명히 해야 합니다.
- 빈 상태: 왜 비어 있는지와 다음 행동을 알려야 합니다.
- 용어 일관성: 같은 개념은 같은 이름으로 불러야 합니다.
- 접근 가능한 문장: 문장은 쉽고 명확해야 하며, 모호하거나 배제적인 표현을 피해야 합니다.
- 톤과 보이스: 문구는 브랜드보다 먼저 사용자의 상황, 위험도, 감정 상태에 맞아야 합니다.
