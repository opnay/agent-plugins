## 사용자 스펙 의도

- 콘텐츠 디자이너는 배너·카드뉴스·에디토리얼·소셜 콘텐츠 같은 시각 콘텐츠를 뜻한다.
- 동일 문구·색·패턴의 반복은 연결·리듬과 강조에 필요하며, 맥락에 따라 생략·추가할 수 있다.

# visual-content-designer 스킬 스펙

## 목적과 경계

- 시각 콘텐츠의 메시지 계층, 이미지·텍스트 구성, 순서·리듬, 매체별 변형을 소유한다.
- UI 라벨·폼 오류·제품 상태 문구는 주 책임이 아니다. 캠페인 전략 전체와 외부 게시는 소유하지 않는다.
- 대표 표면: `skills/visual-content-designer/SKILL.md`.

## 핵심 처리 계약

- 대상, 전달 목표·핵심 메시지·근거, 채널·실제 노출 크기·비율·사용 자산을 확인한다.
- 정보 우선순위와 읽기 순서에 따라 헤드라인·본문·이미지·출처·브랜드·CTA의 역할을 정한다.
- 이미지와 문구가 동일 설명만 중복하는지, 서로 필요한 정보와 정서를 보완하는지 판단한다.
- 카드뉴스·시리즈는 도입·전개·마무리의 연결과 각 단위의 독립 노출을 함께 고려한다.
- 동일 용어·색 역할·모티프·그리드를 반복해 묶음을 인식하게 한다. 강조는 횟수·위치·크기·변주로 조절한다.
- 앞선 설명을 생략한 장도 단독 공유·crop·재정렬 시 맥락을 잃지 않게 필요한 정보를 복원한다.
- 형식별 crop·safe area·타이포·정보량을 다시 구성한다. 알 수 없는 플랫폼 수치를 사실처럼 만들지 않는다.
- 접근 가능한 읽기 크기·대비·대체 설명을 고려한다. 근거 없는 수치·추천사·제품 약속을 만들지 않는다.
- 도구 선택은 작업 환경에 맡긴다. 생성·렌더링하지 않은 이미지를 제작 완료로 보고하지 않는다.

## 출력과 검토 질문

- 요청에 맞는 구성안·스토리보드·매체별 규칙 또는 실제 시각 산출물을 제공한다.
- 메시지·반복·변주·crop의 이유와 실제 확인한 크기·범위를 설명한다.
- 시리즈 전체와 독립 노출 양쪽에서 의미·식별성·강조가 유지되는가?

## 독립성·확장

- bundle 내 직접 실행 가능. 프로젝트 맥락, design-base의 색·공간·타이포·반복 reference를 명시적으로 읽는다.
- 아트·크리에이티브 디렉션은 제공된 결정이 있으면 입력으로 사용한다. 선행 호출은 요구하지 않는다.
- 새 매체는 메시지 전달과 실제 형식 제약이 달라질 때 기준을 추가한다.
