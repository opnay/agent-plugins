# pro-planner User Spec Intent

- `pro-` skill series로 서비스 기획자 역할을 추가하고 싶다.
- 서비스 기획자 skill은 화면을 어떻게 꾸밀지보다 어떤 문제를 왜, 어디까지, 어떤 성공 기준으로 해결할지 판단해야 한다.
- `pro-planner`는 사용자 문제, 대상 사용자, 가치, MVP 범위, 우선순위, 요구사항, 큰 흐름, acceptance criteria, tradeoff, designer/engineer handoff를 다뤄야 한다.
- 프로젝트 생성이나 기능 추가처럼 넓은 요청을 받으면 요구사항을 분리하고, 문제를 제품 방식과 기능 단위로 나눈 뒤 기획과 디자인/개발 handoff로 이어지는 판단에 집중해야 한다.
  - `pro-planner`를 이 방향으로 바로 보강할까요?
    - `pro-planner 보강` 선택. 추가 메시지: 실행 루프가 아니라, 문제 분해에 좀더 초점을 맞춘 기획을 집중하자.
- 넓은 요청을 분해할 때 단순 기획 축뿐 아니라 디자인 시스템처럼 다음 역할이 판단하기 전에 필요한 부가 기획 표면도 함께 나와야 한다.
