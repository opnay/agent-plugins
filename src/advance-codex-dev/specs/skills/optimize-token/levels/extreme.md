# `extreme` 단계 게이트

`extreme`은 `standard`를 상속하고, 출력 형태를 라벨/값 또는 고정 필드 중심으로 덮어씁니다.

## 적용

- "상태만", "라벨만", "한 줄로", "최대한 압축" 명시
- 원문이 상태표, 숫자 목록, 점검 목록, 고정 제목 묶음처럼 구조화됨
- 설명 없이 짧은 진행 상태 라벨만 필요함
- 일반 "짧게/간결하게"만으로는 진입 불가

## 덮어쓰기

- 형태: `필드: 값.`, 필수 필드별 압축 항목, 압축 상태표, `다음: 파일 확인.`
- 절대 보존: 실패/미실행/막힘/불충분 검증, 승인 상태/경계, commit/push/PR/publish/release/version bump 경계, 보안/개인정보/법률/의료/금융 예외, 남은 위험과 다음 행동
- 이동: 결정 이유, 검증 불충분 이유, 승인, 위험이 숨겨지면 해당 부분은 `standard`; 안전한 절차 설명이 필요하면 `light`

## 예시

- `검증은 아직 실행하지 않았고 회귀 위험이 있습니다.` > `상태: 미검증. 위험: 회귀 가능.`
- `커밋은 실행하지 않았고 push와 PR도 승인되지 않았습니다.` > `커밋: 미실행. push/PR: 미승인.`
