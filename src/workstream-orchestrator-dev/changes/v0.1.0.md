# workstream-orchestrator 0.1.0 Change Spec

## 변경사항 요약

- cross-domain·mixed investigation-and-action orchestration plugin을 도입합니다.
- 하나의 cohesive lifecycle skill과 bounded task/result·model routing·shared-state 계약을 제공합니다.
- dev source와 runtime release surface를 분리하고 자동 trigger 경계를 명시합니다.

## 변경 목적

조사와 실행이 함께 있는 목표를 독립 workstream으로 안전하게 위임하고, 메인 에이전트가 결과를 검증·통합하는 instruction-only plugin의 최초 release 범위를 정의합니다.

## 릴리즈 노트 기준

- 독자에게 보이는 변화: `$workstream-orchestrator:orchestrate-workstreams`로 bounded subagent orchestration을 사용할 수 있습니다.
- 호환성 영향: 신규 plugin이므로 기존 호출자 영향이 없습니다.
- migration 필요 여부: 없습니다.
- 운영자/사용자가 알아야 할 검증 결과: canonical skill·plugin validator와 repository build 검증이 필요합니다.

## 기록 근거

- 관련 커밋: 없음
- 관련 세션 기록: 신규 `workstream-orchestrator` 0.1.0 작성 요청

## 변경 상세

### Plugin boundary와 usage surface

- 목적: pure research methodology 및 software-only 3단 orchestration과 구분되는 mixed-workstream 경계를 제공합니다.
- 범위: manifest, README, plugin spec
- 관련 표면: `.codex-plugin/plugin.json`, `README.md`, `specs/plugin.md`
- 검증: trigger separation과 namespace를 확인합니다.

### Cohesive orchestration skill

- 목적: dispatch gate부터 whole-result verification까지 하나의 runtime lifecycle을 제공합니다.
- 범위: skill spec, runtime skill, agent metadata, concise references, trigger fixture
- 관련 표면: `specs/skills/orchestrate-workstreams.md`, `skills/orchestrate-workstreams/`
- 검증: quick validator, scenario fixture, task/result·model·ownership 계약을 확인합니다.

### Release surface

- 목적: dev source를 `workstream-orchestrator` release namespace로 변환합니다.
- 범위: root release plugin build
- 관련 표면: `workstream-orchestrator/`
- 검증: `specs/`, `changes/`, `-dev` namespace가 release에 없는지 확인합니다.

- 현재 명시 모델 지원 범위는 `gpt-5.6-terra`와 `gpt-5.6-sol`입니다.

## 검증 기준

- JSON parse, dev manifest name·path·version alignment
- canonical `quick_validate.py`와 `validate_plugin.py` 통과
- `pnpm build:plugin workstream-orchestrator` 성공
- release exclusion, namespace, 인접 plugin trigger, 7개 routing scenario 확인
- final diff에 범위 외 변경이 없음

## 정식 규칙 승격 여부

- change spec에만 남길 release/migration 이력: 0.1.0 최초 도입과 검증 기록
