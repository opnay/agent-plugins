# codex-creator v0.1.0 Change Spec

## 변경사항 요약

- `plugin-creator`와 `skill-creator`의 runtime·개발 spec을 `advance-codex`에서 `codex-creator`로 이동합니다.
- 두 호스트 manifest와 marketplace, README·운영 문서의 소유 경로와 호출 안내를 맞춥니다.
- `advance-codex`는 `optimize-token`과 `asd-ste100`을 제공합니다.

## 변경 상세

### 제작 책임 분리

- 목적: plugin·skill 제작을 하나의 일관된 번들로 제공합니다.
- 범위: `codex-creator/`, `src/codex-creator-dev/`, 기존 플러그인 사용 표면과 두 marketplace.
- 처리 계약: 두 creator runtime의 본문·metadata를 보존합니다. skill spec은 대표 경로만 정정합니다.
- 버전: 새 플러그인은 `0.1.0`, 기존 `advance-codex`는 진행 중인 `0.1.1`을 유지합니다.

## 비목표

- canonical system creator 제공·설치, creator 행동 변경, 사용자 설치 cache 갱신, commit·push·릴리즈.

## 호환성 및 마이그레이션

- `$advance-codex:plugin-creator` → `$codex-creator:plugin-creator`
- `$advance-codex:skill-creator` → `$codex-creator:skill-creator`
- 로컬 마켓을 갱신하고 `codex-creator`를 선택해야 새 식별자를 사용할 수 있습니다. 기존 cache나 사용자 지침은 자동 변경하지 않습니다.
- 두 creator에는 각각 canonical system 동명 skill이 필요합니다.

## 검증 기준

- 새 플러그인의 필수 구조와 두 creator 경로가 존재하며 기존 플러그인에는 남지 않습니다.
- 두 creator runtime이 이동 전과 동일하며 skill spec은 대표 경로 외에 달라지지 않습니다.
- 두 호스트 manifest의 공통 metadata와 실제 skill·prompt가 일치합니다.
- 두 marketplace의 기존 항목 순서를 보존하고 동일 이름·순서·실제 경로를 사용합니다.
- 활성 문서의 호출·상대 링크, skill frontmatter와 `git diff --check`를 검증합니다.
- clean-context read-only 검증으로 plugin 구성과 skill spec/runtime 정합성을 확인합니다.
- 실제 설치·native discovery·모델 행동 비교는 구조 이동 검증과 구분합니다.

## 정식 규칙 승격 여부

- 지속 책임 경계는 두 plugin spec과 사용 표면이 소유합니다.
- 이동 이력과 기존 호출의 마이그레이션은 이 change spec이 소유합니다.
