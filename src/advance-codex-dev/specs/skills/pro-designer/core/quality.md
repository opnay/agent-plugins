# Quality Criteria

## 정의

Quality는 UI, UX, Content가 제품 맥락 안에서 완성도와 신뢰를 유지하는지 판단하는 공통 기준입니다.

## 기준

- 완성도: 정상 상태뿐 아니라 로딩, 빈 상태, 오류, 비활성, 권한 없음, 성공 상태까지 같은 설계 언어로 이어져야 합니다.
- 접근성: 대비, focus, 읽기 순서, 터치 목표, 보조기술 친화성이 유지되어야 합니다.
- 일관성: 같은 의미의 정보, 행동, 상태는 같은 규칙으로 표현되어야 합니다.
- 디자인 시스템: 기존 패턴, 컴포넌트, 토큰, 상호작용 규칙과 충돌하지 않아야 합니다.
- 적응성: 화면 크기와 입력 방식이 달라도 정보 우선순위와 행동 가능성이 유지되어야 합니다.
- 맥락 적합성: 화면 유형과 사용 상황에 맞는 밀도, 표현성, 장식 수준을 선택해야 합니다.
- 확장성: 콘텐츠 길이, 데이터량, 언어, 지역 차이가 달라져도 구조가 쉽게 깨지지 않아야 합니다.
- 체감 성능: 지연, 전환, 로딩 표현은 제품이 멈췄다는 인상을 주지 않아야 합니다.
- 제품 신뢰감: 위험, 오류, 결제, 삭제, 권한 같은 민감한 상황에서도 안정감이 유지되어야 합니다.
- 상호작용 일관성: 입력, 저장, 전송, 선택, 취소 같은 행동의 반응 규칙이 일관되어야 합니다.
- 오류 회복성: 위험 행동 방지, 되돌리기, 재시도, 손실 방지 기준이 제품 전반에서 유지되어야 합니다.
