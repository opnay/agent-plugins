# advance-subagent 0.1.0 Change Spec

## 변경사항 요약

- `deep-research`와 `workstream-orchestrator`의 기존 skill을 `advance-subagent` 한 플러그인으로 이관합니다.
- 두 skill의 역할, trigger, routing, 산출물 계약은 재해석하지 않습니다.
- dev·release namespace와 manifest·README·spec·fixture를 새 플러그인 이름에 맞춥니다.
- 기존 두 공개 플러그인과 marketplace 항목을 `advance-subagent`로 교체합니다.

## 변경 목적

서브에이전트 관련 심화 실행 방법을 하나의 설치·관리 단위에서 제공하되, 이번 변경에서는 기존 skill 계약을 보존합니다.

## 릴리즈 노트 기준

- 독자에게 보이는 변화: `deep-research`와 `orchestrate-workstreams`를 하나의 플러그인에서 호출합니다.
- 호환성 영향: 기존 plugin namespace는 유지하지 않습니다.
- migration 필요 여부: 기존 명시 호출을 새 namespace로 변경합니다.
- 운영자/사용자가 알아야 할 검증 결과: 두 skill의 runtime·reference·fixture 보존, namespace 변환, release 격리, marketplace 정합성을 검증해야 합니다.

## 변경 상세

### Plugin bundle

- 목적: 두 기존 skill을 서브에이전트 심화 방법이라는 하나의 설치 단위로 제공합니다.
- 범위: manifest, README, plugin spec, 두 skill spec
- 관련 표면: `.codex-plugin/plugin.json`, `README.md`, `specs/plugin.md`, `specs/skills/`
- 검증: skill 선택 기준, 독립 실행 가능성, 두 namespace를 확인합니다.

### Skill 이관

- 목적: 기존 `deep-research`와 `orchestrate-workstreams` 계약을 새 플러그인에서 그대로 제공합니다.
- 범위: runtime skill, reference, agent metadata, trigger fixture
- 관련 표면: `skills/deep-research/`, `skills/orchestrate-workstreams/`
- 검증: 이전 skill의 경계·data flow·routing·산출물 필드가 보존됐는지 확인합니다.

### 공개 surface 교체

- 목적: 공개 설치 단위를 `advance-subagent` 하나로 전환합니다.
- 범위: root release build, marketplace, root README, 기존 release·dev source 제거
- 관련 표면: `advance-subagent/`, `.agents/plugins/marketplace.json`, `README.md`, `src/`
- 검증: 기존 plugin 경로·namespace 제거, 새 source path·policy·category와 release 파일 구성을 확인합니다.

## 비목표

- 두 skill의 역할 재분담 또는 lifecycle 통합
- trigger, model routing, evidence, report, task/result contract 재설계
- compatibility shim 또는 기존 namespace 유지
- MCP, app, hook, executable runtime dependency 추가
- version bump, 브랜치 변경, commit, push, PR

## 호환성 및 마이그레이션

| 기존 호출 | 새 호출 |
| --- | --- |
| `$deep-research-dev:deep-research` | `$advance-subagent-dev:deep-research` |
| `$workstream-orchestrator-dev:orchestrate-workstreams` | `$advance-subagent-dev:orchestrate-workstreams` |
| `$deep-research:deep-research` | `$advance-subagent:deep-research` |
| `$workstream-orchestrator:orchestrate-workstreams` | `$advance-subagent:orchestrate-workstreams` |

## 검증 기준

- dev manifest name·folder·version이 `advance-subagent-dev`와 `0.1.0`으로 일치합니다.
- canonical skill·plugin validator가 dev와 release surface에서 통과합니다.
- 두 skill의 reference와 trigger fixture가 모두 포함되고 JSON·YAML·CSV가 파싱됩니다.
- dev metadata·fixture는 `$advance-subagent-dev:*`, release는 `$advance-subagent:*`를 사용합니다.
- `pnpm build:plugin advance-subagent --force`가 두 skill을 포함하고 `specs/`·`changes/`를 제외합니다.
- release에서 `[DEV]`, `advance-subagent-dev`, 이전 plugin namespace 검색 결과가 0건입니다.
- marketplace 항목과 root README가 `./advance-subagent` release surface와 일치합니다.
- clean-context verifier가 각 skill의 spec/runtime 계약 보존과 plugin usage 정합성을 PASS로 판정합니다.

## 정식 규칙 승격 여부

- normative spec 또는 runtime 문서로 승격할 지속 규칙: plugin boundary, skill selection, 독립 실행, 새 namespace
- change spec에만 남길 release/migration 이력: 기존 두 플러그인의 통합과 namespace 변경
