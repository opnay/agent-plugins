## 사용자 스펙 의도

- `pro-` 스킬 시리즈로 `pro-designer`를 만들고 싶다.
- `pro-designer`는 좋은 디자인을 주관적으로 칭찬하는 스킬이 아니라, Codex가 제품과 UI 작업에서 디자이너 관점의 판단 기준을 적용하게 하는 스킬이어야 한다.
- `pro-engineering`이 문제 해결, 구현 판단, 검증을 다룬다면 `pro-designer`는 사용자 맥락, 정보 구조, 시각 위계, 상호작용 상태, 접근성, 반응형 품질을 다뤄야 한다.
- `pro-designer`는 UI 기준, UX 기준, user flow 기준을 충분히 다뤄야 한다.
- `pro-designer`의 core 기준 축은 UI, UX, Content, Quality로 정리한다.
- `pro-designer`는 core 기준과 별도로 Color 축을 두어 색상 시스템과 색감을 판단하게 한다.
- Color 축은 파스텔톤 같은 색감 선택을 단순 취향 평가가 아니라 사용자 이해, 상태 의미, 접근성, 브랜드 적합성 기준으로 판단해야 한다.
- `pro-designer`는 core 기준과 별도로 Tone & Expression 축을 두어 목표 톤의 분류, 적합성, 구성 요소, 경계를 판단하게 한다.
- Tone & Expression 축은 trust-first, friendly, premium, energetic, technical, calm, playful 같은 목표 톤을 화면 목적과 사용자 맥락에 맞게 선택하고, 색상, 명도, 채도, 대비, 여백, 표면감, 타이포그래피, 문구 태도로 구성하게 한다.
- `pro-designer`는 core 기준과 별도로 Branding 축을 두어 브랜드 식별성, 브랜드 자산, 브랜드 색상 역할, 브랜드 일관성, 기능 의미와의 충돌 방지를 판단하게 한다.
- Branding 축은 톤 자체가 아니라 특정 브랜드로 일관되게 인식되는지, 그리고 브랜드 표현이 CTA, 상태색, 위험색, 제품 이해를 침범하지 않는지 판단해야 한다.
- `pro-designer`는 core 기준과 별도로 Surface & Form 축을 두어 카드, 패널, 버튼, 입력 영역의 표면감, 깊이, 형태, 물성을 판단하게 한다.
- Surface & Form 축은 realistic material, raised card, inset surface, flat panel 같은 표현 방식을 취향이 아니라 정보 위계, 행동 가능성, 화면 맥락, 디자인 시스템 적합성 기준으로 판단해야 한다.
- passive trigger는 "UI 다듬어줘", "디자인 개선", "화면이 어색해", "대시보드 만들어줘", "랜딩 페이지" 같은 자연어에서 좁게 동작해야 한다.
