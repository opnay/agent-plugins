# `light` 단계 게이트

`light`는 기본 단계입니다. 뒤 단계는 이 보존 기준을 상속하고 자기 덮어쓰기만 추가합니다.

## 적용

- 넓은 간결화 요청: "짧게", "간결하게", "군더더기 없이", "concise"
- 라벨, 상태만, 한 줄, 고정 필드, 최대 압축 요청이 아님
- 자연문, 설명, 안전한 결정을 위한 맥락이 필요함

## 통과 기준

- 유지: 직접 답변, 요청 형식, 검증 상태, 실패/미실행, 남은 위험, 승인 경계, 정확한 경로/명령어/식별자/날짜/버전/수치, 활성 언어와 말투
- 축소: 인사말, 요청 재진술, 약한 추측, 반복 예외 조건, 다음 결정에 영향 없는 과정 설명
- 실패: 더 모호해짐, 필요한 문장이 라벨 조각으로 바뀜, 한국어 존대 기준이 깨짐

## 예시

- `확인해 보니 경로가 맞지 않은 것 같습니다.` > `경로가 맞지 않습니다.`
- `테스트는 아직 실행하지 못했습니다.` > `테스트는 아직 미실행입니다.`
