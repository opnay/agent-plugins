# baton-relay-dev 0.1.0 Change Spec

## 변경사항 요약

- `baton-relay-dev` 신규 dev plugin source를 추가한다.
- 대표 skill `manager`를 추가한다.
- worktree별 fresh subagent lifecycle, commit/rebase handoff, prepared commit integration, cleanup gate를 초기 계약으로 고정한다.
- 20개 scenario evaluation에서 드러난 read-only, generated output, commit approval, missing verification, unresolved conflict 경계를 보강한다.

## 변경 목적

큰 작업을 메인 에이전트가 직접 구현하지 않고, git worktree로 격리된 subagent 작업 단위에 맡긴 뒤 commit 단위로 회수하는 orchestration plugin을 시작한다.

## 릴리즈 노트 기준

- 독자에게 보이는 변화: `baton-relay` plugin과 `manager` skill이 추가된다.
- 호환성 영향: 신규 plugin이므로 기존 호출자 migration은 없다.
- migration 필요 여부: 없음.
- 운영자/사용자가 알아야 할 검증 결과: manifest, skill metadata, release surface, marketplace entry를 검증해야 한다.

## 변경 상세

### 신규 plugin source

- 목적: worktree-based subagent orchestration을 하나의 coherent bundle로 제공한다.
- 범위: `src/baton-relay-dev/.codex-plugin/plugin.json`, `README.md`, `specs/plugin.md`.
- 관련 표면: plugin manifest, README, plugin spec.
- 검증: JSON parse, release build, release manifest 확인.

### manager skill

- 목적: 메인 에이전트가 manager로 동작하고 subagent가 bounded worktree task를 수행하는 계약을 제공한다.
- 범위: `specs/skills/manager.md`, `skills/manager/SKILL.md`.
- 관련 표면: skill spec, runtime skill.
- 검증: skill metadata, runtime/dev-only path leak, spec/runtime alignment, 20개 scenario evaluation 확인.

## 비목표

- 실제 subagent spawn 도구 구현.
- GitHub PR, push, release publication 자동화.
- 특정 언어/프레임워크 구현 전략.

## 호환성 및 마이그레이션

- 신규 plugin이므로 기존 plugin migration은 없다.
- 향후 skill 추가 시 plugin boundary를 worktree relay orchestration으로 유지한다.

## 검증 기준

- `pnpm build:plugin baton-relay --force`
- JSON parse for dev and release manifests, marketplace.
- release surface에 `specs/`와 `changes/`가 없어야 한다.
- `manager` runtime skill이 dev-only spec path를 실행 지시로 포함하지 않아야 한다.

## 정식 규칙 승격 여부

- normative spec 또는 runtime 문서로 승격할 지속 규칙: subagent lifecycle, rebase handoff, prepared commit integration, cleanup gate.
- change spec에만 남길 release/migration 이력: initial creation history.
