# flow output 계약

- interview: snapshot, risks, locked brief, in/out scope, tradeoffs, decision boundary, constraints, acceptance, confirmations, residual ambiguity.
- design: next main flow, type, ownership, scope, non-goals, completion, verification, approval boundary, handoff, candidates, blocker.
- reporting: result, verification method/result, residual risk, next intake condition.
- review: required main-flow review result, not active routing or handoff authority.
- handoff: handoff condition after main-flow review.
- check: brief vs active contract separated; reporting loop vs handoff separated; blocker visible.
